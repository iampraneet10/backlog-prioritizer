How RICE scoring works

RICE score = Reach × Impact × Confidence ÷ Effort
Reach
People or events affected per period
Impact
0.25 (minimal) to 3 (massive)
Confidence
How sure you are, as a percentage
Effort
Person-weeks to build

How MoSCoW tagging works

Tag what the release needs. Ranking by MoSCoW first keeps every Must above the rest, then orders each group by RICE.

Must
The release fails without it
Should
Important, but not critical
Could
Nice to have if time allows
Won’t
Not in this release
